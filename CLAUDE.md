# Project goal

Create a starter project for citizen developers taking part in a hackathon.
Participants have around **3 hours for prompting** to build a working demo.
Choose tools and features that help them make progress within that time.

Keep setup short, instructions clear, and the code easy to change through prompts.
Do not require hosted databases, cloud provisioning, or complex infrastructure to run the starter.
Prefer local storage, embedded databases, or sample data when persistence is needed.
Keep external services optional, with a local or mock fallback for the core demo.

Focus on the smallest useful demo. Avoid adding architecture, dependencies, or setup steps that consume the limited hackathon time.

Support only Cursor, Claude, and ChatGPT. Keep agent entry point files limited to `AGENTS.md` and `CLAUDE.md`.
