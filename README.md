# Next.js

A standard Next.js App Router starter with TypeScript, Tailwind CSS, and ESLint.

## Getting started

Use Node.js 20.9 or newer.

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Edit `src/app/page.tsx` to get started.

## Checks

```sh
npm run lint
npm run build
```

Run `npm start` after building to serve the production build locally.
